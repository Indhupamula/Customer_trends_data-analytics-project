# Customer Behavior Data Analysis

An end-to-end data analytics project analyzing customer shopping behavior
using Python, SQL, and Power BI.

## Project Overview

This project analyzes customer shopping behavior to identify purchasing
patterns, customer segments, product preferences, and factors influencing
customer purchases.

The project follows an end-to-end analytics workflow:

- Data cleaning and preparation using Python
- Exploratory Data Analysis using Pandas
- Business analysis using SQL
- Interactive dashboard development using Power BI
- Business insights and recommendations

## Tech Stack

- Python
- Pandas
- NumPy
- SQL
- MySQL
- Power BI
- Jupyter Notebook

## Dataset

The analysis uses customer shopping behavior data containing information
such as:

- Customer demographics
- Product categories
- Purchase amounts
- Discounts
- Reviews
- Shipping preferences
- Subscription status
- Previous purchases

## Project Workflow

### 1. Data Preparation

The raw dataset was loaded into Python and analyzed using Pandas.

Steps included:

- Data inspection
- Handling missing values
- Removing inconsistencies
- Data type conversion
- Feature transformation
- Exploratory data analysis

### 2. SQL Analysis

The cleaned dataset was loaded into a SQL database.

SQL queries were used to answer business questions related to:

- Customer segmentation
- Purchase behavior
- Product performance
- Customer loyalty
- Discounts
- Subscription behavior
- Revenue patterns

### 3. Power BI Dashboard

The analyzed data was connected to Power BI to create an interactive
dashboard.

The dashboard provides insights into:

- Customer demographics
- Sales performance
- Product categories
- Customer segments
- Subscription behavior
- Purchase trends

## Key Business Questions

Some of the questions investigated include:

1. Which product categories generate the most revenue?
2. Which customer segments have the highest purchase frequency?
3. Does subscription status influence customer spending?
4. Which products receive the highest ratings?
5. How do discounts affect purchasing behavior?
6. Which customers demonstrate strong loyalty?
